# Basic HTML & CSS Demo

A simple web project demonstrating basic HTML structure and custom CSS styling rules, including classes, IDs, nested inline elements, and external link styling.

---

## 📁 File Structure

```text
.
├── index.html   # Main HTML layout file

Features
HTML Heading Hierarchy: Demonstrates the use of <h1>, <h2>, and <h3> heading tags.

Text Formatting & Custom Styling:

Applied shared class styles (.head) across multiple headings.

Used ID selectors (#bglime, #para) for specific element overrides.

Included inline <span> elements to highlight specific text styling within headers and paragraphs.

List & Navigation: Features an unordered list (<ul>) containing links to external platforms (Facebook, Google, and Twitter).

CSS Properties Applied:

Custom background colors (brown, lime).

Custom text colors (blue, white, green, red, black).

Custom font size (25px on specific paragraphs).
